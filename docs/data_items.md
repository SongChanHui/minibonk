## 2. 아이템 중첩(Stacking) 4대 유형 공식

동일한 아이템을 여러 개 획득했을 때 수치가 누적되는 계산 방식입니다.

| 타입 코드 | 유형 명칭 | 계산 공식 | 설명 및 예시 |
| :---: | :--- | :--- | :--- |
| **Type A** | **합산형 (Linear)** | $\text{최종값} = \text{기본 수치} \times n$ | 중첩마다 기본 수치가 그대로 정직하게 가산됨.<br>• *행운의 풀잎 (7.5%) 3개: $7.5\% \times 3 = +22.5\%$* |
| **Type B** | **지수 감쇠형 (Diminishing)** | $\text{최종값} = 1 - (1 - \text{기본값})^n$ | 중첩할수록 한계 효용이 감소하여 100% 무적/확률 도달을 방지함.<br>• *잔상의 반지 (12%) 3개: $1 - (1 - 0.12)^3 = 31.9\%$* |
| **Type C** | **단일 고정형 (Unique)** | 효과 고정 (1회 획득 후 풀 제외) | 2개 이상 보유할 수 없거나 중첩 의미가 없는 특수 규칙 아이템.<br>• *분노 각인경, 파멸의 왕관, 시간 결박구* |
| **Type D** | **특수 확장형 (Special Expansion)** | 메커니즘별 규칙 적용 | 상한 증가, 투사체/번개 수 증가, 기준 스탯 비례 스케일링 등.<br>• 번개 수 증가: $\text{개수} = n$<br>• 킬 상한 증가: $\text{상한} = \text{기본 상한} \times n$<br>• 획득당 증가량 배가: $\text{증가폭} = \text{기본폭} \times n$ |

## 3. 폭발(Explosion) 아이템 공통 규칙 및 범위 데이터

게임 내 폭발 효과를 유발하는 모든 아이템은 통일된 범위 공식과 연쇄 폭발 방지 룰을 따릅니다.

- **공통 폭발 반경 공식** (플레이어 크기 = 1 유닛 기준):
  $$\text{폭발 반경} = 4.0 + (n - 1) \times 2.5 \quad (n = \text{보유 개수})$$
- **연쇄 폭발 방지 규칙 (`isExplosion`)**:
  - 폭발 피해로 적이 타격받거나 사망했을 때는 어떠한 폭발 아이템도 재발동하지 않습니다. (무한 연쇄 렉 방지)

| 아이템 보유 개수 ($n$) | 계산식 | 폭발 유효 반경 (Units) |
| :---: | :--- | :---: |
| **1개** | $4.0 + (1 - 1) \times 2.5$ | **4.0** |
| **2개** | $4.0 + (2 - 1) \times 2.5$ | **6.5** |
| **3개** | $4.0 + (3 - 1) \times 2.5$ | **9.0** |
| **4개** | $4.0 + (4 - 1) \times 2.5$ | **11.5** |
| **5개** | $4.0 + (5 - 1) \times 2.5$ | **14.0** |

> **적용 아이템 (6종)**: [파멸의 손](#파멸의-손), [폭발 임계제](#폭발-임계제), [파문의 망토](#파문의-망토), [폭발 가시 가면](#폭발-가시-가면), [충격 폭발탄](#충격-폭발탄), [생명 반향석](#생명-반향석)
